# HTML 交付规范

所有完成的产品拆解最终必须交付为用户授权工作区中的独立 HTML 文件。

## 基础模板

复制并改写 [HTML 报告模板](../assets/report-template.html)。替换所有 `{{中文占位符}}`。不得留下占位文字或空章节；不适用的章节直接删除，不要填充泛泛内容。

## 质量要求

- 同时适配手机和桌面；
- 默认使用浅色、高对比主题；
- 打印时不得出现大面积深色背景；
- 使用语义化标题、表格、列表、折叠区和可访问标签；
- 除非确有必要且已获允许，不依赖外部网络资源；
- 开头附近展示证据等级图例；
- 关键结论和图中节点旁显示证据编号；
- 已确认、推断、建议和未知在视觉上清晰区分；
- 窄屏下表格和复杂图可以横向滚动，不能裁切内容。

## 推荐报告骨架

1. 标题与一句话摘要
2. 查看范围与证据边界
3. 产品分类
4. 当前模式的专项分析
5. 四层分析
6. 状态冲突与风险检查
7. 规则/组件—证据追溯表
8. 最值得继续验证的问题

模式专项章节遵循对应参考文件。

## 图表规范

- 状态图、时序图、ER 图和带标签架构图适合时优先使用 Mermaid。
- Mermaid 过密时使用 HTML/CSS 泳道或 SVG。
- 必须包含图例和线型含义。
- 图中出现的每个关键组件都必须能在追溯表中找到依据。

## 交付前验证

1. 使用 HTML 解析器检查语法；
2. 搜索 `TODO`、`{{...}}`、示例产品名和空模板章节；
3. 确认用户要求的章节与证据图例都存在；
4. 如包含本地证据链接，验证链接路径；
5. 确认没有嵌入凭证、Cookie、Token 或敏感浏览器数据；
6. 条件允许时在工作区查看器中打开文件。

最终回复提供可点击的绝对路径，并简要说明报告内容。
